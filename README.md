# The Digital Archive Alchemist

Tired of persistent low-storage warnings and stressful digital alerts? The Digital Archive Alchemist is an autonomous multi-agent system running locally on UGREEN AI NAS (UGOS) to continuously transmute unstructured data into organized, deeply indexed knowledge bases.

## Core Architecture & Sub-Agents
1. **The Crucible (Intake & Purification)**: Monitors storage pools (`/mnt/user/vault/`), strips malicious script vectors, and normalizes metadata types.
2. **The Philosopher (Transmutation & Synthesis)**: Executes local lightweight embedding generation, calculating pattern frequencies and building semantic node connections (`alchemist_index.json`).
3. **The Aegis (Sovereign Shield)**: Implements custom firewall protective barriers to block telemetry leaks and protect personal memories or code bases.

## Target Tracks
* Personal Memories
* Work Automation & Productivity
